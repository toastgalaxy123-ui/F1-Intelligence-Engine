# S8-B interactive strategy workspace

## Implementation map

- The existing Next.js workspace owns the draft, submitted request, current result and earlier result. Preset, driver, session, horizon and applied assumptions resolve a new API snapshot. An unapplied context edit hides the results until it is applied or discarded.
- Strategy Lab keeps the S8-A score and optimizer contracts. Its common-marker display can use any completed policy as the visual reference. That selection changes display deltas. The frozen engine stay-out comparator and recommendation remain bound to the submitted run.
- The API serves optional discrete checkpoint traces from a completed worker alongside the unchanged canonical result. Each trace is bound to the original analysis ID and result checksum. Manual and conditional branches use the actual driver-specific crossing events. The display compares shared recorded checkpoint IDs. It joins no gaps with invented motion.
- The timeline uses recorded policy decisions, pit events, service intervals and race-control events. A predicted pit-entry time stays labeled as a prediction. Clean-air totals, following, race-control and pit quantities come from their respective engine ledgers. The interface leaves them as separate measurements.
- Robust Strategy uses the frozen scenario rows for comparable outcomes, regret and Pareto membership. The selected executable policy is held across futures. Perfect-information oracles remain retrospective. No scenario probabilities are assigned.
- The shared-box preset exposes matched policies generated by the existing optimizer. The combined objective sums weighted driver elapsed times as specified by the declared engine objective. Shared service order and waiting come from ordered service starts. Neither metric implies a championship-point objective.
- Workspaces store up to 24 bounded JSON documents in the current browser origin. The shelf can save inputs or a completed request with its receipt. Import and reopen verify sources, model and snapshot against the local API. Reproduce re-executes saved inputs and compares the original result checksum before showing a result.
- The API still uses one isolated worker, four outstanding jobs, a 35-second wall deadline, a sampled 720 MiB RSS limit and a bounded cache. Cancellation sends an actual DELETE after job admission and displays the worker's terminal response.

## Additive contracts

| Route | Purpose |
| --- | --- |
| `POST /api/v1/policy-catalog` | Enumerate legal strategies for a pinned snapshot and requested stop bound |
| `GET /api/v1/analyses/{id}/details` | Read completed manual or conditional trace data in integer microseconds |
| `POST /api/v1/workspaces/verify` | Validate the versioned file and its model, source and request identity |
| `POST /api/v1/replays` | Existing route. Checks the saved result checksum during recomputation |

The workspace file is `s8b-workspace-v1`. It contains a UUID, title, timestamps, normalized context, snapshot, declared assumptions, source and model hashes, optional analysis and optional result receipt, and a display reference. It contains no executable data. JSON exports are limited to 15 KiB in the browser and 16 KiB at API ingress. Rename unsupported files by creating a new investigation under the current source context. Automatic model substitution is disabled.

## Reproduce

Start both loopback services using the local guide. Node 24 was used for browser and TypeScript unit validation. [Local setup](local.md)

```powershell
python -m pytest -q
python -m ruff check src tests scripts
npm --prefix apps/web run test:unit
npm --prefix apps/web run typecheck
npm --prefix apps/web run lint
npm --prefix apps/web run build
npm --prefix apps/web test
python scripts/verify_s8b.py
```

Set `F1RI_S8B_SCREENSHOTS` and `F1RI_UI_REPORT` to absolute output paths before recording the Chrome suite. With the tests, browser report and prior-run folders available, pass `--ui-report` and `--tests-passed` to the verification script. Use `--rerun-priors` with a fresh `--prior-prefix` to regenerate earlier engine studies.
