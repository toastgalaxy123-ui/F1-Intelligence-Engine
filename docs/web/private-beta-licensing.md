# Private-beta asset and data review

| Material | Current use | External release dependency |
| --- | --- | --- |
| Formula 1 terminology, race names, driver names and team names | Factual labels for the selected research context. Identify the service as independent research. | Review the planned use of protected marks, product naming and branding before a wider release. [Formula 1 guidelines](https://www.formula1.com/en/information/guidelines.4EOKE9RRqevL4niTK9kWyt) |
| Circuit visuals, car art, driver photographs and logos | Strategy maps and charts render from application data. The existing `night-race.webp` is generic generated artwork. No official driver photographs, team logos or official circuit imagery are bundled in the web asset directory. | Retain provenance for approved assets. Obtain permission before incorporating protected photographs, logos and other artwork. |
| OpenF1 historical timing and location | Frozen provenance and quantitative summaries support archived research. The gateway protects application routes and the release assets sit outside the web server's public directory. | Confirm redistribution rights for archived timing/location records, derived graphics and exports before extending audience or serving raw data. Historical API availability and upstream documentation do not constitute a publication grant for all underlying rights. [OpenF1 documentation](https://openf1.org/docs/) |
| Other historical source archives | Rehearsals exercise the checked existing S6/S7 artifacts. The app gives invited users access to curated summaries and owned exports. | Review individual source and provider terms for the intended audience, including timing, telemetry and session data before any new distribution. |
| Fonts and UI packages | Fontsource packages supply Barlow Condensed and Geist under the SIL Open Font License. The lockfile records Next.js, React, Lucide and their dependencies. | Preserve the package licenses and notices when distributing the frontend. Review all dependency notices from the locked deployment set. |

The private validation archive includes documented results and synthetic-account browser captures. It contains no database, provider configuration, session credentials or raw historical source archive. Access control supports an invitation-only research beta. Publication and redistribution permissions depend on the intended deployment and source terms.
